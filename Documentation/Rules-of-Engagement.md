# Rules of Engagement

## Scope

Target yang diperbolehkan:

* DNS Server (192.168.56.20)
* Ubuntu Server (192.168.56.10)
* CyberOps Client (192.168.56.30)

## Allowed Activities

* DNS Enumeration
* DNS Spoofing
* DNS Tunneling
* Traffic Monitoring

## Restricted Activities

* Serangan ke luar lingkungan laboratorium
* DoS yang menyebabkan VM crash
* Penghapusan log sistem

## Monitoring

Seluruh aktivitas diamati menggunakan Security Onion dan tcpdump.
